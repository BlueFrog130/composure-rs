# Each published crate has its own version

Up to 0.1.3 the six published crates shared one version (one knope `[package]`, `version.workspace = true`, `v<version>` tags), so any change file bumped and republished all six: #19 added two fields to `composure::types::Webhook` and released five crates with identical code, churning versions for users who depend on one crate and filling every changelog with entries that didn't apply to it (#20). Each crate is now its own knope package (`[packages.<crate>]`): `version` in its own `Cargo.toml`, its `[workspace.dependencies]` entry (what the other crates require of it) and its `Cargo.lock` entry move together, its notes go to its own `CHANGELOG.md`, and it is tagged `<crate>/v<version>` with a GitHub release per crate. Change files name the crates they touch (`composure: minor`); a crate nobody names keeps its version and isn't republished. The release workflow publishes, in dependency order, every crate whose version has no tag yet, then `knope release` tags them; the 0.1.3 commit got a `<crate>/v0.1.3` tag per crate so the first run had nothing to release, and the root `CHANGELOG.md` and `v<version>` tags stay as the shared history. knope doesn't bump dependents, and a breaking change to a crate is a breaking change to the crates that re-export its types (every crate uses `composure`'s in its API, and `composure` re-exports `composure_macros`): without a new version of them, crates.io would only offer ones built against the old crate and users upgrading it would get two copies. `scripts/check-change-files.sh` (CI, on every pull request) requires `major` for every published crate that depends on one with `major`, directly or not, and rejects names that aren't published crates. A non-breaking bump needs nothing more: the workspace requirement rises with it, and a dependent that isn't republished keeps a compatible requirement. The `composure_bot` follows `composure`'s releases only. The alternatives were keeping one version but publishing only changed crates (versions would no longer say what is on crates.io, and a crate's version could skip numbers) and keeping it as it was while on 0.x.
