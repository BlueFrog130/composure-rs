# Views are how a bot answers; the Theme is removed

Supersedes ADR 0009. The Theme (ADR 0009) was designed for embeds: it fills in unset colors, the author on the first embed and the footer on the last, and renders errors as `error`-colored embeds. For Components V2 it does one thing, setting `accent_color` on unset top-level Containers, so its name promises more than it does for V2 messages. It also applies on only some paths. Interaction Responses and deferred edits are themed, but REST messages are not, because their bodies are the user's. So any bot that also posts through REST sets its colors itself: Composure's own bot (`bots/composure/src/ui.rs`) gives every Container an explicit accent, because its announcements would otherwise look different from its replies. For that little effect, every Route's `dispatch*`, `Invocation`, `Ctx` and `DeferredCtx` carries an `Option<&'static Theme>`. Nested Apps merge Themes with `__themed`, `MessageCallbackData` has a skipped `unthemed` flag, `Unthemed` wraps responses, and `Theme::apply` walks every response. All of it is removed: `Theme`, `#[app(theme = ..)]`, `RouteDefinition::THEME`, `InteractionHandler::theme`, `ctx.theme()`, `Unthemed` and `HandlerError::response_with`. Colors become the user's own `const`s. A consistent look comes from wrapper Views that set them, one per tone (`<ui::Success title="Saved">..</ui::Success>`, as `ui.rs` already does), and these work the same through every path, REST included. Handler errors are the one output the framework renders itself. They are rendered by a hook: `#[app(.., errors = render)]` with `fn render(error: &HandlerError) -> InteractionResponse`, so a V2 bot can answer errors as a Container. At most one App in a tree sets it (two is a compile error, as with `events`), the root forwards to it, and dispatch hands it to the Adapter and to `DeferredCtx` as a single `fn` pointer, with no cascade. Without the hook, errors are the ephemeral text of `HandlerError::response()`.

With the Theme gone, `rsx!` becomes the main way to write a response. A `View` therefore carries the whole message, not just its components. It holds the ephemeral flag (`.ephemeral()`), `allowed_mentions`, and attachments: `<File>`, `<Thumbnail>` and `<Item>` take an `Attachment` value as well as a URL string, register the file on the View and set `attachment://<name>` themselves. `Ephemeral(..)` and `Update(..)` still wrap other outputs. REST bodies (`CreateMessage`, `CreateFollowup`, `EditMessage`, `ExecuteWebhook`) are built from a `&View`, which sets `IsComponentsV2` and the files. There is no `<Embed>` tag: Components V2 messages cannot carry embeds, so embeds stay builder-only for non-V2 messages. When Discord rejects an interaction callback, the user sees only "interaction failed" and nothing is logged. So Discord's limits (40 components, 4000 characters of text, 5 buttons per row, 25 options, 100-character `custom_id`s) are checked in one walk when a View becomes a response, and a violation becomes a `HandlerError`. A markup level without `{..}` children has its counts checked at compile time. `rsx!` must keep IDE support while code is half-typed. It parses with rstml's `parse_recoverable` (`recover_block(true)`), collects every error with `syn::Error::combine` instead of stopping at the first, and still expands what parsed, falling back to `View::default()`, so rust-analyzer keeps type-checking and completing `{..}` blocks in incomplete markup. Built-in tags expand with the tag's own span on the type path, both opening and closing tag, so hovering and go-to-definition work on `<Container>`. A hidden `composure::view::tags` module, one item per tag with a doc-commented item per attribute (the field attributes and the special ones like `primary`, `url`, `on:click`), is referenced with each attribute's span. That gives tag and attribute completion and hover docs, and is the single source the guide's tag reference is checked against. Rejected: keeping `Theme` as a palette without auto-fill, which would be an ordinary `const` with a framework name and `ctx.theme()` threaded for nothing; extending auto-fill to REST bodies, which would rewrite messages the user built (the rule ADR 0009 rightly kept) and still only cover accents; and an `<Embed>` tag, which V2 forbids.
